# Security Policy

## Supported Versions

Security fixes are applied to the latest published preview or stable release. Unsigned previews are explicitly marked and are not publisher-verified by Gatekeeper.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting for `arthursvpb/scoped-folder-mirror`. Do not include real backup contents, paths, bookmark data, volume identifiers, credentials, or other personal data. Expect an acknowledgement within seven days.

## Release Boundary

Stable downloadable releases require Developer ID signing, Hardened Runtime, secure timestamping, notarization, and stapling. Until those controls are available, builds are published only as prereleases labeled `UNSIGNED PREVIEW`.
